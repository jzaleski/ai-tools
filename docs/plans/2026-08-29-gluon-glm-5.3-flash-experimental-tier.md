# Gluon (GLM-5.3-Flash) Experimental Tier Implementation Plan

> **For agentic workers:** Use skills/coder to implement each task. Read the full task description — don't summarize or skip steps.

**Goal:** Add a new text-only experimental-namespace model alias, `jzaleski/experimental/gluon` (GLM-5.3-Flash, `unsloth/GLM-5.3-Flash-GGUF`, `UD-Q4_K_XL`, 6-part split), across `bin/run-model`, `bin/run-router`, the experimental INI preset template, the opencode provider config, and both `AGENTS.md`/`README.md`. Multimodal support (for `gluon` and a backfilled `boson` mmproj) is explicitly deferred — documented as "Future Work" only, not implemented.

**Architecture:** Pure pattern-matching against the existing `jzaleski/experimental/quark`/`jzaleski/experimental/boson` aliases — same helper functions (`require_model`, `require_split_model`), same hardware tuning (`q8_0`/`q8_0` KV cache, `1024`/`256` batch/ubatch, `--reasoning-preserve`, `--cache-reuse 256`, `--cache-ram -1`, `--load-mode mlock`, `--predict 262144`), no new mechanisms. `gluon` differs from `quark`/`boson` only in: no speculative decoding (deferred pending upstream MTP confirmation for GLM-5.3-Flash), `temp=1.0`/`top-p=0.95`/no `top-k` sampling, `reasoning_effort=max`, and `1,048,576` context.

**Tech Stack:** Bash, INI templates, JSON (opencode config), Markdown (docs)

**Design doc:** `docs/specs/2026-08-29-gluon-glm-5.3-flash-experimental-tier-design.md`

```bash
# Experimental tier: GLM-5.3-Flash (Z.ai/GLM-5 series), text-only.
#
# Note: GLM-5.3-Flash support in llama.cpp is currently only available via
# Unsloth's llama.cpp fork/PR (https://github.com/ggml-org/llama.cpp/pull/27754
# or unslothai/llama.cpp@glm5next/upstream) — not yet merged into mainline
# llama.cpp, i.e. not yet in the Homebrew `llama.cpp` package this repo's
# bin/install-dependencies installs. Building/installing that fork is left
# to the operator; this script only constructs the llama-server invocation.
#
# No speculative decoding: the GGUF's commit metadata references
# glm5-next.attention.indexer.index_share_mtp=true, suggesting MTP draft
# tensors may be present, but Unsloth's own documented llama-cli invocation
# for GLM-5.3-Flash does not pass --spec-type draft-mtp, and GLM-5.3-Flash
# support itself is still on an unmerged PR. Revisit once MTP support for
# GLM-5.3-Flash is officially confirmed upstream.
#
# No multimodal variant yet: GLM-5.3-Flash is natively multimodal and ships
# a root-level mmproj-F16.gguf, but a `-multimodal` sibling alias is
# deferred — see docs/specs/2026-08-29-gluon-glm-5.3-flash-experimental-tier-design.md
# ("Future Work") for the planned default/<tier>-multimodal-style pattern.
#
# Settings below follow Unsloth's GLM-5.3-Flash guide
# (https://unsloth.ai/docs/models/glm-5.3-flash):
# - Context is set to the model's stated maximum (1,048,576 / "1M"), same
#   treatment as experimental/quark.
# - `temp 1.0` / `top-p 0.95` matches Unsloth's "Default Settings (Most
#   Tasks)" profile rather than their "DeepSWE" agentic-benchmark profile
#   (temp 0.95 / top-p 1.0), to stay consistent with every other tier in
#   this repo.
# - `top-k` is intentionally omitted: Unsloth's GLM-5.3-Flash examples never
#   pass it, matching the same omission already applied to
#   experimental/quark.
# - `reasoning_effort` is set to "max", GLM-5.3-Flash's highest available
#   effort (its only options are low/high/max).
run_experimental_gluon() {
  local base_model="${MODELS_DIR}/unsloth/GLM-5.3-Flash-GGUF/UD-Q4_K_XL/GLM-5.3-Flash-UD-Q4_K_XL.gguf";
  require_split_model "${base_model}" "unsloth/GLM-5.3-Flash-GGUF" "UD-Q4_K_XL/GLM-5.3-Flash-UD-Q4_K_XL.gguf" 6;

  local first_part="${base_model%.gguf}-00001-of-00006.gguf";

  exec llama-server \
    --model            "${first_part}" \
    --alias            jzaleski/experimental/gluon \
    --host             "${HOST:-"127.0.0.1"}" \
    --port             "${PORT:-"8081"}" \
    --flash-attn       on \
    --n-gpu-layers     -1 \
    --batch-size       1024 \
    --ubatch-size      256 \
    --ctx-size         1048576 \
    --cache-type-k     q8_0 \
    --cache-type-v     q8_0 \
    --chat-template-kwargs '{"reasoning_effort":"max"}' \
    --reasoning-preserve \
    --cache-reuse      256 \
    --cache-ram        -1 \
    --load-mode        mlock \
    --predict          262144 \
    --presence-penalty 0.0 \
    --repeat-penalty   1.0 \
    --min-p            0.0 \
    --temp             1.0 \
    --top-p            0.95;
}

tier="default/medium";
```
